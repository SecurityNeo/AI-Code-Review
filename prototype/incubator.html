什么是规则孵化台？

规则孵化台是智能评审规则的"制造工厂"。它从海量的历史评审 Issue 中自动发现规律、聚类分析、提炼生成候选规则，经过多轮 LLM 验证后发布到规则库，并持续监控规则质量，形成完整的规则全生命周期管理闭环。

LLM 驱动 自动聚类 模拟测试 质量监控

系统运行依赖：LLM 对话模型（必须）用于智能提炼和模拟测试；Embedding 模型（可选，未配置时降级为关键词匹配）；历史 Issue 数据（必须）作为规则孵化的原材料。

孵化流水线（9 个阶段）

阶段一：自动发现
系统自动执行 · 零人工干预
1
原始 Issue 池
收集所有未被规则命中的历史 Issue，是规则孵化的"原材料仓库"。
输入 未被规则覆盖的 Review Issue
过滤 按配置时间窗口（默认 30 天）筛选
产出 待聚类的 Issue 集合
2
聚类分析
按维度+语言+严重级别三维分组，通过关键词重叠度（Jaccard）将相似 Issue 聚成簇。
算法 Jaccard 关键词相似度 + 结构化分组
参数 最小簇大小（默认 2）、时间窗口
产出 N 个有效 Issue 簇，每个簇 ≥ 最小簇大小
3
候选规则
每个有效簇自动生成一条候选规则，状态为"草稿"，包含基础信息。
生成 自动推断名称、维度、语言、严重级别
状态 草稿（draft）→ 等待智能提炼
入口 也可手动创建，绑定指定 Issue
阶段二：智能精化
LLM 驱动验证 · 逐条处理候选人
4
智能提炼
调用 LLM 分析源 Issue 样本，自动生成精炼的规则名称、规则描述和审查 Prompt。
输入 源 Issue 列表（最多取 5 条样本）
模型 配置的主 LLM / 备用 LLM
产出 精炼的 name / description / prompt
状态 草稿 → 可发布（ready）
5
相似检测
对比现有规则库，检测候选规则是否与已有规则重复或高度相似，避免重复定义。
比对 候选规则 vs 所有已启用规则
算法 Jaccard 关键词相似度（阈值 0.5）
去重 Code 冲突时自动重命名
6
模拟测试
用 LLM 对正例（源 Issue 代码片段）和反例（同类未命中代码）进行判定验证。
正例 源 Issue 的代码片段（应该命中）
反例 同维度 Issue 的未命中代码（不应命中）
判定 LLM 逐条判定 YES / NO，输出准确率
阶段三：发布与监控
人工确认 + 自动巡检
7
发布规则
审核通过的候选规则正式发布到评审规则库，可在各项目中独立配置启用。
触发 人工在候选规则面板点击「发布」
约束 Code 唯一性校验、非重复规则
产出 ReviewRule 记录 + 项目默认配置
8
回溯匹配
新规则发布后，自动在历史 Issue 中查找可被命中的记录，补全规则与 Issue 的关联。
策略 L1 结构过滤 → L2 关键词预匹配 → L3 语义比对
范围 最近 N 天的历史 Issue（可配置）
产出 ReviewIssueRuleMatch 关联记录
9
健康监控
定期评估规则的命中、拒绝和同类未命中数据，发现退化或误报过高并自动告警。
频率 每 7 天自动执行一次巡检
指标 接受率、误触发率、同类未命中率
分级 严重告警（红）/ 警告（黄）/ 正常（绿）

快速上手指南

1
执行聚类分析

进入「流水线」Tab，点击「执行聚类」按钮，设置时间范围（建议 30 天）和最小簇大小（建议 2~3）。

系统将自动扫描 Issue 池，把相似 Issue 聚成簇，每簇生成一条候选规则。执行完成后点击「查看候选规则」跳转到详细列表。

提示：聚类无结果时，尝试降低「最小簇大小」为 1，或扩大时间窗口纳入更多历史数据。
2
完善候选规则

进入「候选规则」Tab，点击规则卡片打开编辑面板。使用「智能提炼」自动生成精炼的 Prompt。

随后使用「相似检测」避免与现有规则重复，再通过「模拟测试」用正例/反例验证规则准确性。测试通过后规则状态变为「可发布」。

提示：Prompt 质量直接决定规则准确性，建议人工审核 LLM 生成的 Prompt。
3
发布规则

确认规则名称、描述、Prompt 准确无误后，点击编辑面板中的「发布规则」按钮。

查看发布确认弹框，确认后规则进入评审规则库。系统会自动为所有项目创建默认禁用配置，需要管理员在项目设置中手动启用。

提示：发布后规则仍可编辑，但修改会直接影响所有已启用该规则的项目评审结果。
4
监控规则质量

进入「规则健康度」Tab 查看所有规则状态。关注「严重告警」（红色）和「警告」（黄色）规则。

根据系统建议优化 Prompt、调整规则参数或停用退化规则。健康监控每 7 天自动执行一次，异常规则会推送告警。

提示：误触发率过高（>50%）的规则建议立即停用并重新提炼 Prompt。
注意事项
!
聚类无结果？ 尝试降低「最小簇大小」为 1，或扩大「时间窗口」纳入更多历史 Issue。
!
Embedding 降级？ 未配置 Embedding 模型时，系统退化为纯关键词匹配，语义聚类不可用。
!
规则发布后仍可编辑，但建议先在候选规则阶段充分测试，避免误报影响评审质量。
!
健康监控每周运行一次，告警规则会自动标红/标黄，请及时关注和处理。
